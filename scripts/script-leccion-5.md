# Guion - Lección 5: Crear una página web sencilla (15 minutos)
**Responsable:** Luis Alonso Huaco Oliva
**Formato:** Narración en off + Grabación de pantalla (CodePen)

## 0:00 - 2:00 | Introducción y Repaso

**[Audio - Luis]:** "¡Bienvenidos al proyecto final del curso! Durante las lecciones anteriores, Brandon, Diana y Piero te enseñaron los bloques de construcción: HTML para el contenido y CSS para el diseño. Hoy vamos a unirlo todo para crear algo increíble: tu propia página de perfil personal. Podrás poner tu nombre, una foto, tus pasatiempos y tus redes sociales. ¡Vamos a ello!"

## 2:00 - 6:00 | Paso 1: La Estructura (HTML)

**[Audio - Luis]:** "Primero, armemos el esqueleto. Vamos a crear una 'tarjeta' que contendrá toda nuestra información. Usaremos una etiqueta `<div>` (que significa división o caja) y le daremos una clase llamada `tarjeta-perfil`.
Dentro, pondremos una imagen con `<img>`, un título principal con `<h1>` para nuestro nombre, un párrafo `<p>` con una pequeña biografía, y una lista `<ul>` para nuestros pasatiempos. Por último, un enlace `<a>` para tu red social favorita. (Escribe el código en vivo mientras hablas)".

## 6:00 - 11:00 | Paso 2: El Diseño (CSS)

**[Audio - Luis]:** "¡Se ve muy aburrido, ¿no? Vamos a darle vida con CSS. Primero, vamos a centrar toda la tarjeta en la pantalla. Para eso, le aplicamos estilos al `body` (el cuerpo de la página). Luego, le daremos a nuestra `tarjeta-perfil` un fondo blanco, bordes redondeados y una sombra para que resalte.
A la imagen la haremos redonda usando `border-radius: 50%`, y cambiaremos los colores de las letras. Puedes usar tus colores favoritos aquí."

## 11:00 - 14:00 | Paso 3: Depuración (El error común)

**[Audio - Luis]:** "A veces, las cosas no salen a la primera. ¿Ves lo que acaba de pasar? La página se rompió. Un consejo de oro: el error más común para empezar es olvidar cerrar una etiqueta o un punto y coma en CSS. Si algo no funciona, revisa tu código letra por letra. Arreglarlo es parte de la diversión de ser desarrollador."

## 14:00 - 15:00 | Cierre y Compartir

**[Audio - Luis]:** "¡Y listo! Acabas de crear tu primera página web desde cero. Te dejo el enlace en la descripción para que uses esta plantilla, cambies los textos y la personalices. En el último video, veremos consejos para seguir aprendiendo. ¡Nos vemos!"
