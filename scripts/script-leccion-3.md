### 0:00 - 2:00 | Introducción y Bienvenida
[Audio - Diana]: "¡Hola a todos! Bienvenidos a la Lección 3 del curso de desarrollo web. Durante las lecciones anteriores, Luis Alonso y Brandon les enseñaron los bloques de construcción principales: qué es una página web y cómo estructurar el código básico con etiquetas HTML. Hoy vamos a dar el siguiente paso para que tus páginas dejen de ser simples textos y cobren vida propia. Vamos a aprender a incorporar imágenes locales, organizar información con listas y conectar nuestro sitio web con el resto de internet mediante enlaces interactivos. ¡Vamos a ello!"

### 2:00 - 5:00 | El Entorno Inicial y la Cabecera (Head)
[Audio - Diana]: "Primero, repasemos las reglas básicas de nuestro documento. Todo archivo HTML profesional inicia con `<!DOCTYPE html>`, que le indica al navegador que usaremos la versión moderna de HTML. Luego, definimos el idioma principal con `<html lang="es">`. En la cabecera o `<head>`, colocamos la etiqueta `<meta charset="UTF-8">` para asegurar que las tildes y la letra ñ se lean correctamente, y el viewport para que la página sea adaptable a cualquier pantalla. En el cuerpo (`<body>`), damos la bienvenida a los usuarios escribiendo un título principal con `<h1>Bienvenidos a mi pagina web interactiva!</h1>` y un párrafo descriptivo detallando lo que haremos hoy."

### 5:00 - 8:30 | Paso 1: Colocando una Imagen (`<img>`)
[Audio - Diana]: "Ahora pasemos a la primera gran herramienta: las imágenes. Para esto, creamos una sección usando un subtítulo `<h2>Colocando una imagen</h2>` y un breve texto introductorio. A continuación, escribimos la etiqueta de imagen `<img src="assets/strawberry.jpg">`. Fíjate que esta etiqueta es muy especial: a diferencia de otras, no necesita una etiqueta de cierre. Además, en el atributo `src` le indicamos la ruta de origen donde está guardada nuestra foto, en este caso dentro de la carpeta de recursos del proyecto. ¡Así de fácil logramos que un gráfico ilustrativo aparezca en nuestra pantalla!"

### 8:30 - 11:30 | Paso 2: Organizando con Listas (`<ul>` y `<li>`)
[Audio - Diana]: "Muy bien, ¿qué tal si queremos ordenar nuestros pasatiempos o actividades favoritas de forma limpia y ordenada? Aquí es donde entran las listas desordenadas. Abrimos una etiqueta `<ul>` que funciona como nuestro contenedor general, y dentro de ella creamos cada uno de los elementos usando la etiqueta `<li>`. Escribimos nuestros elementos: programar páginas web, escuchar música y pintar. El navegador se encargará automáticamente de transformar estas líneas en viñetas ordenadas y profesionales para que cualquier visitante las lea con claridad."

### 11:30 - 13:30 | Paso 3: Conectando con el Mundo (Enlaces `<a>`)
[Audio - Diana]: "Finalmente, toda página web interactiva necesita la capacidad de saltar hacia otras plataformas de internet. Para eso utilizamos la etiqueta de anclaje representada por la letra `<a>`. Dentro de su atributo `href`, colocamos la dirección web de destino, como por ejemplo el enlace oficial de YouTube. Además, le añadimos el atributo `target="blank"` para asegurarnos de que al hacer clic, el sitio se abra en una pestaña nueva sin cerrar nuestra página. Y con esto, ¡nuestra estructura está completa!"

### 13:30 - 14:00 | Cierre y Siguiente Paso
[Audio - Diana]: "¡Y listo! Acabas de aprender a añadir imágenes, listas y enlaces hipervínculos desde cero. Te dejo el código base y la plantilla en el repositorio del equipo para que practiques y personalices tus propios proyectos. En la siguiente lección, continuaremos avanzando con más conceptos clave. ¡Nos vemos ahí!"
