# Fundamentos de Desarrollo Web

## Resumen del Curso
Este curso de 1 hora introduce a estudiantes de secundaria a la creación de sitios web sencillos con HTML y CSS. **¡No requiere descargas!** Solo abre tu navegador web.

**Duración total**: ~60 minutos
**Público objetivo**: Estudiantes de 12 a 17 años sin experiencia en programación
**Prerrequisitos**: Ninguno
**Herramientas necesarias**: **¡Solo tu navegador web!** (Chrome, Firefox, Safari, Edge)

## Secuencia de la Lección

### Lección 1: ¿Qué es el desarrollo web? (5 minutos)
* **Descripción**: Aprende de qué están hechos los sitios web y por qué HTML y CSS son los componentes básicos.
* **Enlace**: [Ver la lección](https://youtu.be/vKtCbd-NcAY)
* **Consejos clave**: Sitios web = Contenido (HTML) + Estilo (CSS).
* **Empieza a programar**: [Abrir CodePen](https://codepen.io/dosullz/pen/QNxdzd)

### Lección 2: Introducción a HTML (10 minutos)
* **Descripción**: Explora las etiquetas HTML básicas y crea tu primera página.
* **Enlace**: [Ver la lección](https://youtu.be/8GwtbXfMk60)
* **Consejos clave**: Usa `<html>`, `<head>`, `<body>`, `<h1>`, `<p>`.
* **Práctica**: [Clic para programar](https://codepen.io/dosullz/pen/QNxdzd)

### Lección 3: Añadir más elementos HTML (10 minutos)
* **Descripción**: Agrega listas, imágenes y enlaces para que tu página sea interactiva.
* **Enlace**: [Ver la lección](https://youtu.be/RjCa7kXdwcU)
* **Consejos clave**: Usa las etiquetas `<ul>`, `<img>`, `<a>`.
* **Práctica**: [Clic para programar](https://codepen.io/dosullz/pen/QNxdzd)

### Lección 4: Introducción a CSS (10 minutos)
* **Descripción**: Dale estilo a tu HTML con colores, fuentes y diseños.
* **Enlace**: [Ver la lección](https://youtu.be/l3BUR3QCxBQ?si=tpichzm-LV0QbAX-)
* **Consejos clave**: Vincular CSS, usar selectores como `body { background-color: blue; }`.
* **Práctica**: [Aplicar estilo con un clic](https://codepen.io/dosullz/pen/QNxdzd)

### Lección 5: Crear una página web sencilla (15 minutos)
* **Descripción**: Combinar HTML y CSS para crear una página de perfil personal.
* **Enlace**: [Ver la lección](https://youtu.be/r-OYkeA-8Pg?si=waJAW1Bss469WAGt)
* **Consejos clave**: Aplicar estilos y depurar errores.
* **Proyecto Final**: [Crea tu Perfil](https://codepen.io/dosullz/pen/QNxdzd)

### Lección 6: Consejos y Próximos Pasos (10 minutos)
* **Descripción**: Mejores prácticas, errores comunes y dónde aprender más.
* **Enlace**: [Ver Lección](https://youtu.be/KHDmNp_3mRo)
* **Consejos Clave**: Valida el código, explora la Documentación Web de MDN.
* **Comparte tu Trabajo**: [Envía tu Creación](https://docs.google.com/forms/d/e/1FAIpQLSd9E13Zf54G91wjZbJPewxtN31ag-HkWE7JzOql-1thUCoteA/viewform?usp=publish-editor)
