# Curso de Fundamentos de Desarrollo Web - Equipo Creatividad

¡Bienvenidos al repositorio del curso de desarrollo web para principiantes! Este proyecto ha sido creado por el equipo **Creatividad** para el curso **1ASI0730 - Aplicaciones Web** de la Universidad Peruana de Ciencias Aplicadas (UPC).

## 📌 Descripción del Proyecto
Este es un curso de aproximadamente 1 hora de duración diseñado para estudiantes de secundaria (12 a 17 años) sin experiencia previa en programación. El objetivo es enseñar los fundamentos de **HTML y CSS** de una manera visual, dinámica y accesible.

**Importante:** ¡No se requiere instalar ningún programa! Todo el código se escribirá en editores en línea gratuitos (CodePen, JSFiddle, Replit).

## 📂 Estructura del Repositorio
*   `/starter-files`: Contiene los archivos HTML y CSS base para que los estudiantes comiencen a practicar.
*   `/completed-examples`: Contiene el código finalizado de cada lección.
*   `/scripts`: Contiene los guiones de texto utilizados en la narración de los videos.
