## Descripción del proyecto

Curso introductorio de aproximadamente 1 hora para estudiantes de secundaria de 12 a 17 años sin experiencia previa en programación. El curso enseña los fundamentos de HTML y CSS mediante videos cortos, ejemplos visuales y prácticas en editores en línea gratuitos.

**No se requiere instalar ningún programa.** Solo se necesita un navegador web moderno: Chrome, Firefox, Safari o Edge.

## Estructura del repositorio

- `/starter-files`: archivos HTML y CSS base para las prácticas.
- `/completed-examples`: código finalizado de cada lección.
- `/scripts`: guiones de narración y apoyo de los videos.
- `course-plan.md`: plan completo del curso, secuencia de lecciones, enlaces a YouTube y enlaces a editores en línea.
- `README.md`: descripción general y uso del repositorio.

## Cómo usar este repositorio

1. Revisa [course-plan.md](./course-plan.md) para acceder al sílabo, videos y prácticas.
2. Abre los enlaces a CodePen, JSFiddle o Replit indicados en cada lección.
3. No necesitas clonar ni descargar el repositorio para realizar el curso. Todo se trabaja en línea.
4. Si deseas revisar el código de ejemplo, usa las carpetas `/starter-files` y `/completed-examples`.
